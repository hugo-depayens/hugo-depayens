<summary><code>$ man ascii_me — как вставить свою фотку / how to insert your photo</code></summary>

<br>

```bash
pip install pillow
python ascii_me.py my_photo.jpg --width 56 --charset blocks --box > portrait.txt
```

| flag | что делает |
|---|---|
| `--width` | ширина в символах. **40–70** — золотая середина для GitHub |
| `--charset` | `blocks` · `soft` · `classic` · `dense` · `matrix` (или своя строка) |
| `--invert` | инвертировать, если фон тёмный |
| `--contrast` | 1.0–2.0, вытягивает лицо из шума |
| `--box` | обвести терминальной рамкой |
| `--out` | сохранить в файл |

Потом открой `README.md`, найди блок с пометкой `ASCII-PORTRAIT SLOT`
и замени всё между `<pre>` и `</pre>` на содержимое `portrait.txt`.

**Совет:** бери фото крупным планом, с контрастным светом и простым фоном —
ASCII не умеет в мелкие детали, зато отлично держит силуэт.
